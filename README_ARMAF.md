# ARMAF — levantamento auditado para catálogo

Este repositório foi autorizado pelo usuário exclusivamente para armazenar o levantamento da lista ARMAF e o plano operacional para o Codex.

## Regra central

Nenhum produto, imagem, volume, concentração, família, público, nota ou descrição pode ser publicado por suposição. Divergências entre o nome recebido, o nome oficial, a variante, o volume ou a embalagem devem permanecer registradas até confirmação documental ou visual.

- Não operar no repositório `carteiradesucesso-code/importtudo`.
- Preservar os preços exatamente como recebidos.
- Não corrigir nomes silenciosamente.
- Não baixar imagem candidata para a pasta de produção.
- Manter a URL original de cada imagem.
